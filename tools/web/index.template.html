使用说明

怎么用
1. 左边输入中文（简体或繁体），右边立刻得到火星文；
2. 右边粘贴火星文，左边立刻还原成中文；
3. 两侧都能直接编辑，互为输入输出，支持整段文字与多行；
4. 把 .txt 文件拖进页面即可转换。

两个关键选项
· 智能消歧：火星文里同一个字往往对应好几个汉字（比如“妑”可以是芭/吧/巴/把/爸）， 勾选后按字频与常用词组做全局最优判断，还原更准；取消则使用在线工具的首个匹配结果。
· 中文侧显示繁体：把中文一侧在简体与繁体之间切换。

说明
本页面完全在本地运行，不上传任何文字，可离线使用（双击本文件即可）。
